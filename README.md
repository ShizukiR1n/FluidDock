# FluidDock

Windows 上的 macOS 风格 Dock。

目前软件已迭代到第一个正式版本，但依然可能会有诸多问题。

## 安装

1. 从 [Releases](https://github.com/ShizukiR1n/FluidDock/releases/latest) 下载 `FluidDock.exe`（约 95 MB，自带运行时，不用另装 .NET）。
2. 放进一个**单独的文件夹**再运行 —— 配置文件 `config\dock.json` 会写在 exe 旁边。

系统要求：Windows 10 1809 或更新，64 位。

## 图标

- 添加快捷方式（.lnk）时，存进去的是它指向的程序，所以图标不会带快捷方式的小箭头。
- 自定义图标支持 png / ico / jpg / bmp；也可以直接选另一个 exe 或 dll，意思是「借用它的图标」。
- 把图片命名成 `程序文件名.png`（例如 `chrome.png`），放进 exe 旁边的 `assets\icons\` 文件夹，也能替换图标。
- 目前不能直接在 Dock 上拖动图标。调整顺序要在设置面板的「应用」列表里，按住一行上下拖动；也可以在 `dock.json` 里调换 `Items` 的先后顺序（见下）。

## 手动编辑配置

「关于 → 打开配置文件」会在资源管理器里定位到 `config\dock.json`。用任意文本编辑器修改，保存后 Dock 自动刷新，不用重启。名称和启动参数这两项面板里没有，只能在这里改：

```json
{
  "Items": [
    {
      "Path": "C:\\Windows\\notepad.exe",
      "Label": "记事本",
      "Args": "D:\\todo.txt",
      "Icon": "assets\\icons\\note.png"
    }
  ]
}
```

| 字段 | 含义 |
|---|---|
| `Path` | 程序、文件、文件夹或网址 |
| `Label` | 名称，设置面板的列表里显示这个 |
| `Args` | 启动参数（可选） |
| `Icon` | 自定义图标（可选），相对路径从 exe 所在文件夹算起 |

## 更新与卸载

- **更新**：「更新 → 检查更新」，需要能访问 GitHub。更新只替换 exe，`config` 里的设置和图标列表原样保留。
- **卸载**：先在设置面板关掉「开机自动启动」，再从托盘退出，最后删除整个文件夹。如果已经先删了文件夹，到任务管理器的「启动」页里禁用 FluidDock 即可。

## 常见问题

- **找不到托盘图标**：在任务栏右下角的「^」里，可以把它拖到任务栏上常驻。
- **挪动 exe 之后「开机自动启动」变成了关**：开机启动记的是 exe 的路径，在面板里重新打开一次即可。
- **改坏了 `dock.json`，启动时报错**：删掉 `dock.json`，下次启动会重新生成（之前添加的图标需要重新添加）。
- **重启资源管理器之后 Dock 不见了**：等几秒，它会自己回来。

## 已知限制

- 「桌面」层级下，有窗口打开时 Dock 会被挡住。
- 只显示在主显示器上。
- 鼠标悬停时不显示应用名称。
- 设置面板按 100% 缩放绘制，在缩放比例较高的屏幕上文字会有点糊。
